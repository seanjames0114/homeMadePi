Connect Home Assistant

Add a token to your .env file to control every device on your network — Hue lights, Kasa plugs, Govee strips, thermostats, locks, and more — all from here.

1
Open Home Assistant → click your name in the bottom-left → Security tab
2
Scroll to Long-Lived Access Tokens → Create Token → copy it
3
Add to .env: HA_TOKEN=your_token_here
4
Restart the dashboard: python3 app.py
Also works without HA — direct Hue and Kasa control is still available below.
